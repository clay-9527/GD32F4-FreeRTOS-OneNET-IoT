# GD32F4-FreeRTOS-OneNET-IoT

本项目基于 GD32F4 系列单片机，完成 FreeRTOS 实时操作系统的移植，并通过 ESP8266-01S WiFi 模块连接 OneNET 云平台，实现嵌入式设备的数据上传与云端监测。

## 项目功能

- GD32F4 平台 FreeRTOS 移植
- 基于 FreeRTOS 的多任务程序框架
- ESP8266-01S WiFi 模块 AT 指令通信
- WiFi 连接与网络状态检测
- OneNET 云平台数据上传
- 串口调试与运行状态输出

## 项目用途

本项目适合作为 GD32F4 单片机学习 FreeRTOS、WiFi 通信和物联网云平台接入的基础工程，也可作为后续智能硬件、数据采集系统、远程监测系统等项目的底层模板。
